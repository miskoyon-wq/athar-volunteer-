# أثر — بوابة التطوع الذكية 🌿

> **Athar Volunteer** — منصة تطوّع ذكية تربط المتطوع بأفضل الفرص عبر مرشد ذكي، بالعربية أولاً والإنجليزية بالكامل.

<p align="center">
  <strong>تطبيق فلاتر · أندرويد + ويب · Firebase‑اختياري · باك إند مستقل</strong>
</p>

---

## ✨ نظرة عامة

«أثر» يأخذ المتطوع في رحلة قصيرة:

1. **اختيار الجمعية الشريكة** من جمعيات موثوقة.
2. **البيانات الأساسية** — الاسم، المدينة، وتاريخ الميلاد (هجري أو ميلادي مع حساب العمر تلقائياً).
3. **محادثة مع المرشد الذكي** التي تفهم الاهتمامات وأوقات الفراغ.
4. **٣ فرص تطوعية مطابقة** مع نسبة توافق واضحة لكل فرصة.
5. **تقديم الطلب** ومتابعة حالته لحظياً + ردّ من منسّق التطوع.

بالإضافة إلى مجموعة كاملة من الأدوات: ساعات التطوع والشارات والشهادة، الفرص القريبة، الإشعارات، ومشاركة الفرص عبر واتساب.

## 🚀 المزايا الرئيسية

| الميزة | الوصف |

| 🤖 **مرشد ذكي** | محادثة تفهم الاهتمامات وتقترح الفرص الأنسب |
| 🎯 **مطابقة ذكية** | أفضل ٣ فرص مع نسبة توافق مئوية |
| 🎂 **تاريخ الميلاد هجري/ميلادي** | حساب العمر تلقائياً + قاعدة الحد الأدنى ١٥ سنة (التقويم الأكثر تحفّظاً) |
| ⏱️ **ساعات وشارات** | تتبّع ساعات التطوع وجمع الشارات والحصول على شهادة |
| 📍 **الفرص القريبة** | تصفية الفرص حسب المدينة وفتح الموقع على الخريطة |
| 🔔 **إشعارات** | تنبيهات بالفرص الجديدة وتحديثات الطلبات |
| 💬 **تواصل مباشر** | واتساب / اتصال / بريد مع إدارة التطوع |
| 🌐 **مزدوج اللغة** | عربي (RTL) وإنجليزي بالكامل |
| 📱 **نمط PWA** | نسخة ويب قابلة للتثبيت على الجوال |

## 🏗️ البنية التقنية

```
flutter_app/
├── lib/
│   ├── config/      إعدادات التطبيق وقنوات التواصل
│   ├── data/        النصوص (عربي/إنجليزي)، الجمعيات، الفرص، المدن
│   ├── screens/     كل الشاشات (استقبال، بيانات، محادثة، مطابقة، ...)
│   ├── services/    الخدمات (الحساب، المرشد الذكي، الساعات، المشاركة، العمر)
│   ├── state/       إدارة الحالة (Provider)
│   ├── theme/       الألوان والخطوط والهوية
│   └── widgets/     المكوّنات المشتركة
├── backend/         الباك إند (Python · استقبال + لوحة منسّق + API)
├── web/             نسخة الويب (PWA): splash + SEO + manifest
├── android/         إعدادات أندرويد (التوقيع مُستثنى من Git)
├── test/            اختبارات الوحدة والواجهة
└── docs/            الأدلة الرسمية (Play · Backend · Web · Runbook)
```

### التقنيات
- **Flutter 3.35.4** · **Dart 3.9.2**
- **Provider** لإدارة الحالة
- **intl** للتواريخ والتوطين · **hijri** للتقويم الهجري (أم القرى)
- **shared_preferences** + **Hive** للتخزين المحلي
- **url_launcher** للاتصال وواتساب والبريد
- **باك إند مستقل**: Python (مكتبة قياسية فقط) + SQLite

## 🛠️ التشغيل محلياً

### المتطلبات
- Flutter 3.35.4 / Dart 3.9.2
- (اختياري) Python 3.12 لتشغيل الباك إند محلياً

### خطوات التشغيل
```bash
# 1) جلب الاعتماديات
flutter pub get

# 2) التحليل والاختبارات
flutter analyze
flutter test

# 3) تشغيل نسخة الويب
flutter run -d chrome

# 4) بناء نسخة الويب للإنتاج
flutter build web --release --dart-define=debugShowCheckedModeBanner=false

# 5) بناء تطبيق أندرويد (يحتاج keystore للتوقيع)
flutter build apk --release
flutter build appbundle --release
```

### تشغيل الباك إند محلياً
```bash
cd backend
ATHAR_ADMIN_TOKEN=mysecret ATHAR_DB=./athar.db python3 server.py --port 8090
# لوحة المنسّق:  http://localhost:8090/?token=mysecret
# فحص الحالة:    http://localhost:8090/health
```

## ⚙️ الإعدادات المهمة

كل ما يحتاج تعديلاً تشغيلياً في مكان واحد: **`lib/config/app_config.dart`**

| الإعداد | الوصف |
|---|---|
| `managerPhone` / `whatsappNumber` | أرقام إدارة التطوع |
| `managerEmail` | بريد استقبال الطلبات |
| `web3FormsKey` | مفتاح الإرسال التلقائي بالبريد (اختياري) |
| `backendBaseUrl` | عنوان الباك إند (لوحة المنسّق + الردود) |

> ⚠️ **قبل الإصدار:** حدّث `backendBaseUrl` إلى عنوان الاستضافة الدائمة (Railway / Render / Fly.io) — راجع `docs/backend_hosting_guide.pdf`.

## 🔐 الأمان والخصوصية

- **سياسة الخصوصية** منشورة علناً وتشمل شرط **١٥ سنة** (هجري أو ميلادي).
- **لا يُرفع أبداً** إلى المستودع: مفتاح التوقيع (`*.jks`)، `key.properties`، قاعدة البيانات (`athar.db`)، أي توكنات.
- **لوحة المنسّق محميّة** برمز سرّي (`ATHAR_ADMIN_TOKEN`).
- **التطبيق لعمر ١٥ سنة فأكثر** — يُفرض داخل التطبيق عبر حساب العمر من تاريخ الميلاد.
