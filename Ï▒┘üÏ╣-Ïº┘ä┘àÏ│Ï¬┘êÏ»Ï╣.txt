هذا الملف يشرح خطوات رفع كود تطبيق «أثر» على GitHub خطوة بخطوة.
المشروع Flutter كامل وجاهز (262 ملفاً)، ويشمل التطبيق + الباك إند + التوثيق.

────────────────────────────────────────────────────────────────────────
  الطريقة (أ): رفع بسيط عبر واجهة الويب (الأسهل — بدون أوامر)
────────────────────────────────────────────────────────────────────────

1) افتح: https://github.com/new
2) املأ:
   • Repository name : athar-volunteer
   • الوصف         : بوابة أثر للتطوع — تطبيق Flutter
   • Visibility     : Private  (خاص)
   • لا تختر إضافة README أو .gitignore
3) اضغط "Create repository".
4) في الصفحة التالية اختر رابط "uploading an existing file".
5) فكّ ضغط ملف athar_app_source.zip على جهازك، ثم اسحب كل الملفات
   والمجلدات إلى منطقة الرفع في الصفحة.
6) اكتب رسالة الالتزام: "Initial commit — Athar v1.2.0"
   ثم اضغط "Commit changes".

────────────────────────────────────────────────────────────────────────
  الطريقة (ب): رفع عبر سطر الأوامر (يحفظ كامل تاريخ المشروع)
────────────────────────────────────────────────────────────────────────

> ملاحظة: استخدم ملف athar_app.bundle (يحتوي كل تاريخ Git الكامل).

  # 1) استنسخ المستودع الكامل من الحزمة
  git clone athar_app.bundle athar-volunteer
  cd athar-volunteer

  # 2) أضف المستودع البعيد (بدّل USERNAME باسم حسابك)
  git remote set-url origin https://github.com/USERNAME/athar-volunteer.git

  # 3) ارفع
  git push -u origin main

────────────────────────────────────────────────────────────────────────
  ⚠️  تحذيرات أمنية مهمة جداً
────────────────────────────────────────────────────────────────────────

• لا ترفع أبداً أي من هذه الملفات (مستثناة تلقائياً في .gitignore):
    - android/release-key.jks        (مفتاح توقيع التطبيق)
    - android/key.properties          (كلمات مرور المفتاح)
    - backend/.env                    (متغيّرات البيئة)
    - backend/athar.db                (قاعدة بيانات SQLite)
  فقدان مفتاح التوقيع = عدم القدرة على تحديث التطبيق على Play للأبد!

• أضف ملف google-services.json فقط إذا فعّلت Firebase لاحقاً.
